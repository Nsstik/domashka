# Домашка

Список домашних заданий по дисциплинам.

- Каждая дисциплина — отдельный лист, «Мои дела» всегда в конце.
- Метка «важно» горит красным, «неважно» — синим. Важное само поднимается наверх.
- У задания можно указать срок и написать примечание.
- Сделанное зачёркивается и попадает в раздел «Сделано», а в шапке растут палочки.
- «Итоги семестра» показывают, сколько сделано по каждому предмету.

Все задания хранятся только в браузере того, кто открыл сайт. Можно смело отправлять ссылку одногруппникам: каждый ведёт свой список и чужих заданий не видит. Чтобы перенести список на другое устройство, используй кнопку «Резервная копия».

На телефоне сайт можно добавить на главный экран, и он будет открываться как приложение, в том числе без интернета.
